# XYLO — GitHub Pages

Official landing page for **XYLO: AI Document Intelligence with Chat**

**Tagline**: "Scan. Understand. Ask."

## 📋 What is XYLO?

XYLO is the **international version** of UNAWAIN. Premium on-device document intelligence with AI-powered chat. The killer feature: scan any document, get an instant AI summary, then **ask questions about it** — all offline and 100% private.

**Key Positioning**:
- Premium upfront paid app (no freemium)
- English-first (extensible later)
- Document chat as hero feature
- 100% private & offline
- iPhone 15 Pro+ (6 GB RAM minimum)

## 🎨 Design System Summary

**Color Palette: "Prism"**
- Primary: Violet (#8B5CF6 / #A78BFA in dark)
- Accent: Electric Gold (#FACC15 / #FDE68A in dark)
- Surface: Violet-tinted white/dark (#F3F1FA / #0F0F1A)

**Visual Style**
- Glass morphism (frosted blur cards)
- Diagonal geometric weave pattern background
- Gradient particle animations (violet-gold)
- SF Symbols icons (or web equivalents)

**Typography**
- SF Pro Display/Text (system fonts)
- Spacing: 4px increment scale (xs: 4px → xxxl: 40px)
- Border radius: 16px cards, 12px buttons, 8px chips

## 🎯 Key Differentiators

**XYLO vs UNAWAIN**:
- UNAWAIN = Filipino cultural identity, translation focus
- XYLO = International, minimal, document chat focus

**XYLO vs Competitors**:
- Document chat (not just scanning)
- 100% on-device (not cloud)
- One-time purchase (not subscription)
- RAG-powered citations (not generic AI)
